# SIVchimFinder: Viral Integration and Chimeric Read Detection Pipeline

`chimFinder` is a bioinformatics workflow designed to detect and characterize host-pathogen chimeric integration junctions from paired-end high-throughput sequencing data (e.g., SIV integration within the *Macaca mulatta* host genome). 

The tool processes raw FASTQ reads through adapter trimming, dual host/pathogen alignment, and spliced alignment filtering before running a custom Python detection script (`chimFinder.py`) that identifies chimeric split reads and spanning read pairs, computes topological sequence entropy, groups neighboring integration sites, and annotates candidate loci using host gene annotations (GTF/GFF3).

---

## Architecture and Workflow

1. **Quality & Adapter Trimming (`wrapper.sh`):**
   - Uses `Trim Galore` (`--trim-n`, `-q 5`, `--phred33`, `--length 45`) on paired-end reads (R1 and R2).
2. **Pathogen Alignment (`wrapper.sh`):**
   - Maps trimmed reads against the viral/pathogen reference index using `bowtie2` with local alignment (`--very-sensitive-local --local`).
   - Extracts read headers aligning to the pathogen and filters raw FASTQ files to candidate subsets for downstream processing.
3. **Host Alignment & Splicing Disambiguation (`wrapper.sh`):**
   - Maps pathogen-positive candidate reads against the host reference genome using `bowtie2` (local alignment).
   - Maps reads against the host genome using `HISAT2` (`--very-sensitive --end-to-end --known-splicesite-infile`) to identify reads originating from host splice junctions rather than true viral integrations.
4. **Integration Discovery & Scoring (`chimFinder.py`):**
   - **Split Read Detection:** Analyzes CIGAR strings to identify read-level junctions where one segment aligns to the host and the flanking segment aligns to the pathogen.
   - **Spanning Pair Detection (`wrapperSpan`):** Identifies discordant read pairs where mate 1 aligns to the host and mate 2 aligns to the pathogen (or vice versa).
   - **Host Splice Filtering:** Subtracts reads matching end-to-end spliced alignments generated by HISAT2.
   - **Topological Entropy Calculation:** Computes normalized sequence entropy across alignment junctions to eliminate low-complexity artifacts, homopolymers, and repetitive regions.
   - **Junction Clustering & Closeness Grouping:** Groups integration coordinates within a defined base-pair window (default: 5–30 bp).
   - **Gene Annotation:** Utilizes `pybedtools` to intersect genomic integration coordinates with a host GTF/GFF3 file, assigning nearest gene annotations.

## Requirements and Dependencies

### System & External Tools
Ensure the following command-line tools are installed and accessible in your `$PATH`:
- `bash` (4.0+)
- `trim_galore`
- `bowtie2` (v2.x)
- `hisat2` (v2.x)
- `samtools`, `bcftools`, `htslib`
- `bedtools` (v2.27+)
- `seqtk` (optional, for `--writeReads`)

### Python Environment
The analysis pipeline requires Python 3.7 with the packages specified in `requirements.txt`:
